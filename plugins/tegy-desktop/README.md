# Tegy for Cowork

Tegy helps you work through business decisions, independently review a proposed strategy, and turn supplied material into an executive brief. It requires a Tegy account with available allowance and an internet connection.

## Install and connect

In Claude Desktop, select Cowork and open Customize > Plugins. Add the Rocket-Minds/tegy-plugins marketplace and install Tegy for Cowork. Connect the Tegy Cowork connector through OAuth, and allow Receive Tegy result. Start a new Cowork task and select Solve, Review, or Brief from the slash menu.

## Use Tegy

Solve develops a decision in Claude and sends the finished candidate to Tegy for an independent review. Review assesses a supplied brief, candidate, evidence, and unknowns. Brief rewrites supplied source text for the requested purpose, audience, and format. Hosted Review and Brief requests consume Tegy allowance.

Only the supplied request packet is sent to Tegy. The tools do not retrieve private files, browse links, make payments, or execute the proposed business actions. Supply the relevant source material in the request. A receipt confirms acceptance; it is not a completed review.
