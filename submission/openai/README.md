# OpenAI distribution

This public repository owns the Codex marketplace package. See the
[repository guide](../../README.md) and
[Codex package guide](../../plugins/tegy-openai/README.md) for installation and
use. The OpenAI directory package and its review materials are maintained
separately; this directory does not define that submission.

Use the [connection guide](https://app.tegy.io/mcp) for supported setup paths
and OpenAI's [submission guide](https://developers.openai.com/plugins/deploy/submission)
for current portal requirements. Reviewer credentials belong only in the
secure submission portal, never in this repository.
